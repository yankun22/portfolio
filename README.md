## 📌 Executive Overview

Welcome to the official engineering portfolio of **Alok Vishwakarma**. This monorepo showcases **10 production-grade, specialized web applications** alongside a master exhibition hub. Each system was engineered from first principles to demonstrate high-performance web capabilities rarely delivered in standard commercial applications:

- **🎮 Real-Time 3D WebGL (Three.js)**: Physically Based Rendering (PBR), procedural normal mapping, dynamic studio lighting, and spring-damper exploded view assemblies.
- **🎛️ Low-Latency Web Audio DSP**: In-browser digital audio workstations (DAWs), 3-band parametric biquad equalizers, algorithmic convolution reverb networks, and 60 FPS oscilloscope visualizers.
- **⚡ In-Browser WebAssembly Databases**: Client-side SQLite WASM engines executing real SQL queries with sub-millisecond query latency and zero server dependencies.
- **📊 Stochastic Financial Modeling**: 500-iteration Monte Carlo wealth projection engines computing confidence bands ($P_{10}, P_{50}, P_{90}$) and dynamic FIRE milestone trajectories.
- **🕸️ Graph Theory & Knowledge Systems**: D3.js force-directed cluster simulations, bi-directional `[[WikiLink]]` AST parsers, and infinite vector canvas matrices with Bézier routing.
- **✨ Bespoke Luxury Design System**: 100% mobile-responsive architectural theme styled in *Obsidian, Brushed Titanium, and Warm Ochre Champagne* with zero external CSS frameworks in the client apps.

## 📂 System Architecture Catalog

<details>
<summary><b>1. 💎 WealthFlow — Stochastic Monte Carlo Engine & FIRE Analytics</b></summary>
<br>

- **Multi-Asset Portfolio Tracker**: Real-time asset-allocation donut visualization supporting Cash, Equities, Crypto, Real Estate, and Commodities.
- **500-Iteration Stochastic Monte Carlo Engine**: Projects 10, 25, and 50-year wealth trajectories under log-normal geometric Brownian motion with dynamic volatility, inflation adjustments, and percentile fan bands ($P_{10}, P_{50}, P_{90}$).
- **FIRE Target Architect**: Computes Standard-FIRE, Lean-FIRE, Coast-FIRE, and Barista-FIRE milestones with interactive retirement runway gauges.
- **Multi-Page Export Suite**: Client-side vector PDF generation (via `jsPDF` + `jspdf-autotable`) and CSV data reconciliation.
</details>

<details>
<summary><b>2. 🎧 SoundPulse — Interactive Web Audio DAW & 60fps Oscilloscope</b></summary>
<br>

- **Multi-Source Audio Workstation**: Interactive audio scrubbing and precision slicing ($10\text{px} \dots 300\text{px}/\text{s}$) powered by Wavesurfer.js.
- **Real-Time DSP Hardware Rack**: 3-Band Parametric EQ (Low/High shelf + peaking filter), high-pass/low-pass resonant Biquad filters, and algorithmic convolution reverb.
- **8-Pad Zero-Latency Drum Soundboard**: Procedural Web Audio percussive synthesis with hardware keyboard bindings (`Q, W, E, R, A, S, D, F`).
- **Offline DSP Rendering**: Hardware-accelerated `OfflineAudioContext` baking active DSP effects and convolution reverb tails into 16-bit linear PCM WAV files.
- **60 FPS Phosphor Visualizers**: Real-time oscilloscope, 64-band frequency spectrum analyser, and X/Y stereo phase scope.
</details>

<details>
<summary><b>3. 👟 SpatialCore — Interactive 3D WebGL Product Customization Studio</b></summary>
<br>

- **Procedural 3D Studio Canvas**: Three.js WebGL viewport rendering a multi-component composite footwear assembly with soft PCF shadow maps and OrbitControls.
- **Physical PBR Material System**: Real-time switching across 5 material tiers (Aero Carbon Fiber, Aerospace Titanium, Matte Ultra-Leather, Cyber Polycarbonate, Iridescent Chrome) with procedural bump/normal mapping.
- **Exploded View Animation**: Smooth spring-displacement physics separating sub-components with floating 2D/3D screen-space callouts.
- **4K Studio Snapshot Generator**: High-resolution 1920x1080 branded render cards composited in-memory with instant PNG export.
</details>

<details>
<summary><b>4. 🚨 IncidentPulse — SRE Incident Management & Microservice Dependency Mesh</b></summary>
<br>

- **Simulated Streaming Telemetry Feed**: Real-time anomaly generation simulating 5xx latency spikes, database deadlock cascades, and synthetic alert audio synthesis.
- **Interactive Command Palette (`Cmd+K` / `Ctrl+K`)**: Keyboard-first navigation to filter services, escalate incidents, trigger mock rollbacks, and inspect logs.
- **4-Stage Kanban Triage Board**: Drag-and-drop workflow (`Investigating`, `Identified`, `Monitoring`, `Resolved`) with dynamic SLA countdown timers.
- **Interactive Dependency Topology Graph**: Live SVG microservice dependency graph rendering animated traffic particle flows and health alert halos.
</details>

<details>
<summary><b>5. 🧠 NexusWiki — Bi-Directional Note-Taking & D3.js Force-Directed Knowledge Graph</b></summary>
<br>

- **Bi-Directional `[[WikiLink]]` Parser**: Real-time markdown parser with link autocompletion, inline KaTeX LaTeX rendering, and syntax highlighting.
- **Interactive 2D/3D Physics Graph**: D3.js simulation modeling Coulomb repulsion, Hooke spring attraction, and degree-based node scaling.
- **Backlinks & Unlinked Mentions**: Automatic detection of incoming references with 1-click conversion into bidirectional wiki links.
- **Lossless Vault Export**: Client-side ZIP archive generation bundling notes as individual `.md` markdown files.
</details>

<details>
<summary><b>6. 🎨 CanvasFlow — Hardware-Accelerated Infinite Vector Diagrammer</b></summary>
<br>

- **Infinite Pan & Zoom Viewport**: Coordinate transformation matrix supporting 10% to 500% zoom bounds with cursor-anchored scaling.
- **Magnetic Anchor Connectors**: Shape library (Rectangles, Diamonds, Circles, Database Cylinders) with persistent dynamic Bézier routing.
- **Freehand Catmull-Rom Brushes**: Pressure-simulated smooth vector spline curves with highlighter brushes.
- **Vector & Raster Export Suite**: Multi-scale PNG rasterization (1x, 2x, 3x) and pure standalone SVG vector serialization.
</details>

<details>
<summary><b>7. 🧭 VoyagePlanner — Intelligent Route Planner & Multi-Currency Splitter</b></summary>
<br>

- **Interactive Leaflet Route Engine**: Continuous numbered sequence waypoints with category styling and automated bounding-box fitting.
- **Route Simulation Player**: Real-time marker playback traveling along polyline coordinates at configurable speeds (`1x`, `2x`, `5x`).
- **Drag-and-Drop Timeline**: Multi-day activity scheduler powered by `@dnd-kit` with live distance and pace estimation.
- **Debt Minimization Solver**: Multi-currency expense tracker reducing cross-currency group debts into minimal settlement transactions.
</details>

<details>
<summary><b>8. 🫀 VitalPulse — Biometric Clinical Health Telemetry & ASCVD Risk Studio</b></summary>
<br>

- **Clinical Biometric Telemetry**: Responsive SVG time-series charts for Blood Pressure (AHA stage zones), Heart Rate & HRV, and Blood Glucose (ADA corridors).
- **AHA/ACC 10-Year ASCVD Risk Calculator**: Implements the AHA/ACC Pooled Cohort Equations with dynamic semi-circular gauge visuals.
- **Medication Adherence Engine**: Daily medication scheduler with streak tracking and low-supply refill warnings.
- **Doctor Summary Export**: Standalone printable A4 clinical sheet with 1-click multi-page PDF generation.
</details>

<details>
<summary><b>9. ⚡ CodeForge — In-Browser SQLite WASM Sandbox & Regex Railroad Visualizer</b></summary>
<br>

- **Multi-Tab Sandboxed Playground**: Isolated HTML/CSS/JS editor with sandboxed iframe preview and developer console interceptor.
- **In-Memory SQLite WASM Engine**: Powered by `sql.js` (WebAssembly), executing real SQLite database transactions directly in browser memory with sub-millisecond query latencies.
- **Regex Railroad Visualizer**: Interactive SVG state-machine diagrams generated from regular expression AST tokens with capture group breakdown.
</details>

<details>
<summary><b>10. 🏛️ HavenRealty — Architectural Real Estate, 360° Panorama & Mortgage Engine</b></summary>
<br>

- **Interactive SVG Blueprint Explorer**: Multi-level floor plans with clickable room hotspots and dimension annotations.
- **360° Cylindrical Panorama Viewer**: Smooth HTML5 canvas panorama projection with diurnal lighting choreographies (Dawn, Midday, Golden Hour, Night).
- **Mortgage & Yield Engine**: Real-time loan repayment solver calculating down payments, interest sliders, Gross Rental Yield, Cap Rate, and amortization schedules.
- **White-Glove Tour Booking**: Interactive calendar scheduling with RFC 5545 `.ics` calendar invitation file export.
</details>

## ⚡ Quickstart & Local Evaluation

Prospective clients and evaluators can clone and run any application locally using the monorepo scripts:

```bash
# 1. Clone the repository
git clone https://github.com/yankun22/portfolio.git
cd portfolio

# 2. Launch any application directly from the root
npm run dev:wealthflow     # Launch WealthFlow (Fintech Monte Carlo)
npm run dev:soundpulse     # Launch SoundPulse (Web Audio DAW)
npm run dev:spatialcore    # Launch SpatialCore (Three.js 3D Studio)
npm run dev:incidentpulse  # Launch IncidentPulse (SRE Telemetry)
npm run dev:nexuswiki      # Launch NexusWiki (D3 Knowledge Graph)
npm run dev:canvasflow     # Launch CanvasFlow (Vector Diagrammer)
npm run dev:voyageplanner  # Launch VoyagePlanner (Route Planner)
npm run dev:vitalpulse     # Launch VitalPulse (Clinical Health)
npm run dev:codeforge      # Launch CodeForge (SQLite WASM Playground)
npm run dev:havenrealty    # Launch HavenRealty (360° Architectural Real Estate)
npm run dev:hub            # Launch Master Architecture Hub

# 3. Run validation suite across all applications
npm run lint:all           # Run oxlint across all 10 systems (0 warnings)
npm run build:all          # Run production TypeScript builds
```
