# Security Policy

If you discover a security issue or vulnerability in any of the applications in this repository, please report it privately rather than opening a public issue.

### How to Report
Please send an email to **[contact@alokvishwastudio.in](mailto:contact@alokvishwastudio.in)** with:
- The affected project or component
- Description of the issue
- Steps to reproduce

I'll review and address it as soon as possible. Thank you for helping keep these projects secure!
